Error Detective

Snippet 1:
print("The answer is: " + 42)

Prediction:
TypeError because Python cannot concatenate a string and an integer.

Actual Error:
TypeError: can only concatenate str (not "int") to str

Fix:
print("The answer is: " + str(42))


Snippet 2:
favorite = input("Favorite number: ")
result = favorite + 10
print(result)

Prediction:
TypeError because input() returns a string and 10 is an integer.

Actual Error:
TypeError: can only concatenate str (not "int") to str

Fix:

result = favorite + 10
print(result)
